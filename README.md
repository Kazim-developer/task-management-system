# Task Management System

A full-stack task management application built with **React, Node.js, Express, Prisma, and PostgreSQL**.  
It supports team-based task assignment with session-based authentication.

---

## 🚀 Features

### Authentication

- Session-based login using Passport.js
- Secure protected routes
- Persistent user sessions

### Team Management

- Create teams
- View team members
- Assign roles (Admin / Member)

### Task Management

- Create tasks with due dates
- Assign tasks to team members
- Update task status (Pending → In Progress → Done)
- View personal assigned tasks

### UI Features

- Clean dashboard interface
- Task status indicators
- Team overview pages
- Responsive design

---

## 🛠 Tech Stack

### Frontend
